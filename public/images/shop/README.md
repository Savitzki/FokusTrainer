# Imagens da Loja

Envie arquivos por https://github.com/Savitzki/FokusTrainer/upload/main/public/images/shop

Use nomes curtos, sem espaços ou acentos. Prefira WebP ou PNG; até 500 KB por arquivo.

- Molduras: PNG/WebP transparente, quadrado, 512 × 512 px.
- Cards: quadrado de 1080 × 1080 px ou vertical de 1080 × 1920 px.
- Referências visuais: informe no nome o item relacionado, por exemplo `frame-energy-referencia.webp`.

A vitrine já gera previews funcionais com os estilos do aplicativo. Enviar uma imagem não a vincula automaticamente a um produto: é preciso associá-la ao item no código. Não envie documentos pessoais, credenciais ou imagens sem autorização; esta pasta é pública.
