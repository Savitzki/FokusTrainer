# Capas de perfil

Enviar: `entardecer.png`, `floresta.png`, `noite.png`, `churrasco.png`.
Recomendado: 1200 × 400 px (3:1), arte flat. `object-fit: cover` recorta bordas em telas menores; mantenha a composição importante no centro. O Perfil aplica uma camada escura para legibilidade.

A imagem precisa estar publicada antes de liberar a compra na interface. Arquivos ausentes usam a aparência gratuita, sem imagem quebrada.
